# chat-ui-example

A simple and elegant chat user interface built with vanilla JavaScript, HTML, and CSS.

## Features

- 💬 Clean and modern chat interface
- 📱 Responsive design that works on mobile and desktop
- ⚡ Real-time message sending and display
- ⌨️ Enter key support for sending messages
- 🎨 Beautiful gradient design with smooth animations
- 🕐 Timestamp for each message
- 🔄 Auto-scroll to latest messages

## How to Use

1. Open `index.html` in your web browser
2. Type a message in the input field at the bottom
3. Click "Send" button or press Enter to send the message
4. Messages appear in the chat window with timestamps

## Files

- `index.html` - Main HTML structure of the chat UI
- `style.css` - Styling and visual design
- `chat.js` - JavaScript functionality for chat operations

## Demo Features

- User messages appear on the right side with a purple gradient background
- System/other messages appear on the left side with white background
- Each message displays with a timestamp
- Smooth fade-in animation for new messages
- Custom scrollbar styling

## Customization

You can easily customize the chat UI by modifying:
- Colors in `style.css` (search for gradient values and colors)
- Message behavior in `chat.js` (e.g., add real backend integration)
- Layout in `index.html`
